<h1 align="center" style="margin-top: 0px;font-weight:800;">Loki</h1>
<h3 align="center"><b>A Simple Tool For Managing SSH Localhost Forarding</b></h3>
<br><br />

## About
<p>Loki is a macos app for managing your localhost port forwards across remote machines. It has the following feature set:</p>
<ul>
    <li>Add ports or port ranges to forward</li>
    <li>Multi-machine support</li>
    <li>Toggle ports on and off</li>
    <li>Auto-reconnect</li>
    <li>Port service detection</li>
    <li>Git branch & worktree detection for port services</li>
    <li>Kill a hanging process on a port via the GUI</li>
    <li>Start at login</li>
</ul>

## Installation

Installation is managed by homebrew: 

```
brew tap lermatroid/loki https://github.com/Lermatroid/Loki.git
brew install lermatroid/loki/loki
loki
```
